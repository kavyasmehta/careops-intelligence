# CareOps Intelligence — Frontend

Next.js (TypeScript, App Router, Tailwind, shadcn/ui) frontend for CareOps Intelligence.

See the [project README](../README.md) for the full setup guide, architecture, and disclaimer.

## Local dev (without Docker)

```bash
npm install
npm run dev
```

Requires the backend running separately with `NEXT_PUBLIC_API_BASE_URL` pointed at it (see `.env.example` at the repo root).
